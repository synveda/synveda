# SKIL-4: Scope-targeted distribution

**Epic:** SKIL — Skills registry (spec-compliant + governed) · **Phase:** 3 · **Size:** M

## Description

Skills attach to hierarchy nodes; inject index tier lists skills available to this identity; adapter materialises them into the harness (Claude Code plugin dir).

## Acceptance criteria

user in team A sees team A's skills; team B's are absent; org skills present for both.

# Iris domain context walkthrough

The owned fictional Iris package demonstrates source-backed business meaning
through ordinary Knowledge and review. Its six Git-imported records contain two
canonical entities/glossary entries, an acknowledged delivery-rate definition,
relationship/applicability assumptions, an ambiguity decision and a retry
Procedure. No warehouse or SQL execution is added.

The metric uses percentage units, project/UTC-event-day grain, a unique
ProviderEvent denominator, sandbox and unknown-commit exclusions, and an explicit
unknown result for a zero denominator. The proposed Decision explains that an
unknown commit is neither acknowledgment nor a safe retry. File metadata is
source attribution; only VedaFlow publication makes a definition approved.

Run the isolated, exact-role demonstration:

```sh
bash demos/cpr-41-iris-context.sh
```

The command creates its own real local Git repository, attaches one governed
source descriptor and observes immutable objects through the actual reader.
It publishes six records through Capture and independent review, then requires
the exact metric, Decision and Procedure revisions in a ContextRun. It derives
TaskState from exact Knowledge spans and runs the built CLI against the gateway
for a second user's handoff preview. The preview is measured separately from
saved public-API delivery; it does not claim native vendor execution.

The fixture changes the retry cap from three to five and a metric assumption.
Only those paths become updates. Before review, the published metric remains the
current head and the unapproved alternative does not replace it; source freshness
and authorized health identify the changed evidence. Intended corrections then
follow the existing review/apply path.

A closed local retry harness executes a developmental delayed-ack case. The
small append proposes a delay while preserving the unknown-commit exception.
The complete candidate and fixed case digests are frozen before an independent
registered evaluator runs two held-out variants: a different delayed-ack boundary
and an unknown commit. Reported passing results qualify the candidate for another
human's review. An exact same-item edit publishes its complete frozen hash. This
measures the two controlled fixtures, not universal task quality or causal credit
to every included memory.

Finally, the exact imported retry source is forgotten. Saved/new handoff admission
refuses its derivatives immediately, bounded cleanup reports success, unchanged
refresh does not revive it and an independent glossary item survives. The
optional content-free report records Git identity, CLI-local encoding tokens,
fixed-case counts and cleanup status. Provider usage and cost remain unavailable.
Fixture source dates are rebased before its owned Git commit so each run exercises
a current valid-time version; the package retains its explicit example validity.

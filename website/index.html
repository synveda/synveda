Synveda records sessions from Claude Code, Codex CLI and GitHub Copilot CLI, proposes learnings for a person to review, and adds approved knowledge to later sessions' context. It runs on your infrastructure with PostgreSQL.

For individuals and teams

Keep useful findings.
Decide who gets them.

Knowledge belongs to your personal scope, a workspace or a project. Each revision keeps its source, its review decision and the access rules that apply to it.

Context

At session start, client hooks request relevant approved knowledge within a token budget. See what was selected and why.

Knowledge

Learnings proposed from closed sessions wait for review. Approved revisions keep their source; earlier versions stay readable.

Skills

Review versioned Skill bundles, then sync the approved version to Claude Code or Codex CLI for a person or project.

Tools

Record reviewed MCP server definitions for a project's clients to discover. Synveda never runs the tools itself.

Built-in review and access

A finding has a source.
Sharing has a decision.

Client hooks record session events. When a session closes, a rule-based extractor proposes learnings, with no model API needed. Policy decides whether a change applies at once or waits for named reviewers.

Embedded Cedar policy checks each read and write. PostgreSQL row-level security enforces tenant isolation, and a hash-chained audit log records decisions without copying knowledge bodies.
